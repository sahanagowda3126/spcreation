PORTFOLIO WEBSITE
=================

Files:
- index.html  -> Main website
- style.css   -> Design and responsive layout
- script.js   -> Interactions and animations
- images/     -> Add your profile/project images here

HOW TO USE
----------
1. Extract the ZIP file.
2. Open the portfolio folder.
3. Double-click index.html.
4. The website will open in your browser.

PERSONALIZE
-----------
- Replace "Sahana" with your preferred name.
- Replace the sample email and social links in index.html.
- Add your own photo inside images/ and update the profile section if desired.
- Replace the sample project descriptions with your real projects.
- Update education and skills.

NOTE
----
The contact form is a front-end demo. It does not send email to a server.
For a real contact form, connect it to a backend or a form service.
